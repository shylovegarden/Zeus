# Zeus Discord Server Setup Guide

## Quick Start
1. Go to https://discord.com/create
2. Name: "Zeus Language"
3. Upload logo (⚡)
4. Follow channel structure below
5. Post welcome message
6. Share invite link

---

## Server Structure

### Categories & Channels

**📢 ANNOUNCEMENTS**
- #announcements - Official news (announce-only)
- #releases - New versions, features
- #blog-posts - Auto-post from zeus-lang.org/blog

**👋 WELCOME**
- #start-here - Rules, getting started
- #introductions - New members introduce themselves
- #roles - React to get roles

**💬 GENERAL**
- #general - Main chat
- #random - Off-topic
- #showcase - Share your Zeus projects
- #jobs - Hiring, opportunities

**🔧 HELP**
- #help-beginner - Getting started questions
- #help-advanced - Complex issues
- #bug-reports - Report compiler bugs
- #feature-requests - Suggest improvements

**💻 DEVELOPMENT**
- #internals - Compiler development discussion
- #verification - Formal methods discussion
- #security - Security properties, audits
- #llvm-backend - LLVM development
- #wasm - WebAssembly target
- #evm - Ethereum/EVM target

**🏢 VERTICALS**
- #blockchain - Crypto, DeFi, smart contracts
- #medical - FDA compliance, medical devices
- #aerospace - NASA, DO-178C, space
- #automotive - ISO 26262, cars
- #fintech - Trading systems, banking

**🌐 COMMUNITY**
- #events - Meetups, conferences
- #content - Blog ideas, video scripts
- #translations - Localization
- #ambassadors - Community leaders

**🔒 MODERATOR ONLY**
- #mod-chat - Moderator discussion
- #reports - User reports
- #bot-commands - Admin bot commands

## Roles

### Permission Roles
- @Founder - Full admin
- @Core Team - Moderate, manage channels
- @Moderator - Delete messages, timeout users
- @Contributor - Green name for code contributors
- @Verified - Completed verification

### Interest Roles (Self-assign)
- @Compiler Dev - Working on Zeus compiler
- @Security - Interested in formal verification
- @Blockchain - Crypto/DeFi focus
- @Medical - Healthcare/medical devices
- @Aerospace - Space/aviation
- @Rustacean - Rust developer
- @Student - Learning Zeus

---

## Rules

1. **Be respectful** - No harassment, discrimination, or toxicity
2. **Stay on topic** - Use appropriate channels
3. **No spam** - Don't promote unrelated projects
4. **No piracy** - Don't share copyrighted material
5. **English preferred** - For inclusivity
6. **Use threads** - For detailed discussions
7. **Help others** - Community thrives on mutual support
