## 1 · Canonical Hello World (homepage code panel)

```zeus
// Welcome to Zeus — the language that runs everywhere.

pub fn main() {
    let secret token = 0xDEAD_BEEF;   // erased from binary; never leaks

    let results = parallel {           // dispatches across all available cores
        compute(1), compute(2), compute(3)
    };

    proof { results[0] + results[1] + results[2] == 9 }  // compile-time contract
}

fn compute(n: i32) -> i32 { n * 1 }

test fn sanity() { proof { compute(7) == 7 } }
```

**15 lines. Zero runtime panics. Runs on every chip.**

## 2 · Feature Tab Highlights

### ⚡ Speed
| Feature | Detail |
|---------|--------|
| `parallel {}` block | Emits OpenMP / pthreads / CUDA automatically — zero boilerplate |
| Zero-copy value semantics | No GC pauses; deterministic stack allocation by default |
| MLIR lowering | Zeus → MLIR → LLVM IR pipeline with target-native opt passes |
| Inline SIMD hints | `@simd` attribute auto-vectorises inner loops |

### 🛡 Safety
| Feature | Detail |
|---------|--------|
| `secret` keyword | Value is scrubbed from registers + stack after scope; never appears in output binary |
| `proof {}` block | Compile-time assertion; violated proofs are hard errors, not warnings |
| `enclave {}` block | Code and data are isolated in a hardware enclave (SGX / TrustZone) |
| `safestate {}` block | Defines the global fault handler; replaces bare `SIGABRT` on panic |
| No null pointers | Optional types (`Option<T>`) are the only way to express absence |

### 🔌 Hardware
| Feature | Detail |
|---------|--------|
| 6 baseline targets | x86_64 · aarch64 · ARMv7-M · RISC-V · WASM · CUDA PTX |
| `--target=<triple>` | Single flag selects the entire toolchain + sysroot |
| `extern fn` + FFI | Call C/C++ libraries with a single declaration; Zeus manages the ABI |
| `component struct` | ECS-native value type; cache-line aligned by default |
| `sparse tensor<M,N>` | First-class ML primitive with automatic CSR/CSC lowering |

## 4 · Generated C Code Panel

The playground's right-hand panel shows the C output that the Zeus compiler
emits for `hello_world.zs` targeting `x86_64-unknown-linux-gnu`.

```c
/* AUTO-GENERATED by zeus v0.1.0 — DO NOT EDIT */
/* target: x86_64-unknown-linux-gnu             */

#include <stdint.h>
#include <assert.h>
#include "zeus_rt.h"          /* Zeus runtime shims */

/* secret: value is zeroed on scope exit */
static volatile uint32_t __zeus_secret_token = 0xDEADBEEF;

static int32_t compute(int32_t n) { return n * 1; }

int main(void) {
    /* parallel {} — expanded to OpenMP tasks */
    int32_t results[3];
    #pragma omp parallel sections
    {
        #pragma omp section
        results[0] = compute(1);
        #pragma omp section
        results[1] = compute(2);
        #pragma omp section
        results[2] = compute(3);
    }

    /* proof {} — compile-time contract, elided in release builds */
    assert(results[0] + results[1] + results[2] == 9);

    /* secret erasure — scrub token from memory */
    __zeus_secret_token = 0;
    __builtin_ia32_mfence();

    return 0;
}

/* test fn sanity — compiled only when ZEUS_TEST=1 */
#ifdef ZEUS_TEST
void __zeus_test_sanity(void) {
    assert(compute(7) == 7);
}
#endif
```

## 5 · Playground UI Notes
